Documentação da API

Backend da Academia London Fitness. Cobre conta, perfil, matrícula, locais, fichas, plano da semana, execução série a série e histórico. Senha nunca é gravada em texto — apenas hash bcrypt.

JWT + refresh PostgreSQL Soft delete em fichas 1 plano ativo / usuário 1 sessão in_progress

Como autenticar

Envie o access token em todas as rotas privadas. O access token expira em 15 minutos. Use POST /api/auth/refresh para renovar. 

Authorization: Bearer <accessToken>
Content-Type: application/json

Resposta padrão

{
  "success": true,
  "data": {}
}

Erro

{
  "success": false,
  "error": "token ausente"
}

IDs de exercício usam o catálogo London (exerciseId), não só o sourceId da ExerciseDB. Login atual do app (só e-mail) deve passar a enviar também password.
